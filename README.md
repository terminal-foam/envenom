# Envenom

**给武器与盔甲涂药水** —— 把药水涂在装备上，之后触发时释放对应效果。

Minecraft **1.21.1** · NeoForge **21.1.248** · Java **21**

**本模组在 NeoForge 21.1.248 上开发与测试；暂未证实能否在其它版本中运行。**

---

## 安装

到 [Releases](../../releases/latest) 下载 jar，放进游戏实例的 `mods/` 文件夹。

---

## 玩法

**涂涂层**：副手拿药水，主手拿装备，**右键**。洗掉：水瓶去一层 · 牛奶桶全去 · 蜂蜜瓶只去负面。

剑刃涂层打敌人时触发，剑柄与盔甲对自己生效。

---

## 附魔

五个附魔，只有**剑刃**涂层吃它们：

| 附魔 | 效果 |
|---|---|
| **粘滞** | 有概率不消耗涂层次数 |
| **药水增幅** | 有概率提高效果等级 |
| **叠层** | 攻击时把目标身上已有的负面效果顶高一级 |
| **注射** | 让效果能作用于**末影龙**这类硬编码拒绝效果的生物 |
| **薛定谔的祝福** | 有概率把效果替换成随机的另一种 |
