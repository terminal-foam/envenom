# Envenom

NeoForge 药水涂装模组：把药水涂在武器和盔甲上，在攻击、持握或穿戴时触发效果。
同仓库支持 **Minecraft 1.21.1** 与 **Minecraft 26.1.2** 两条版本线。

| 目录 | Minecraft | NeoForge | Java | 发布 jar |
| --- | --- | --- | --- | --- |
| 仓库根目录 | 1.21.1 | 21.1.248+ | 21 | `envenom-1.0.1-mc1.21.1.jar` |
| `mc26.1.2/` | 26.1.2 | 26.1.2.122+ | 25 | `envenom-1.0.1-mc26.1.2.jar` |

## 下载

到 [Releases](../../releases) 下载对应 jar，**不要混用两条版本线的 jar**。

## 玩法

### 涂药

- 一只手拿**药水**（普通 / 喷溅 / 滞留均可，要求有实际效果），另一只手拿目标物品，右键：
  - 副手药水 + 主手武器 → **剑刃**涂层
  - 副手药水 + 主手盔甲 → **盔甲**涂层
  - 主手药水 + 副手武器 → **剑柄**涂层
- 清洗（同样右键）：
  - **水瓶**：去掉一层涂层
  - **牛奶桶**：去掉全部涂层
  - **蜂蜜瓶**：只去掉负面效果涂层
- 涂层有使用次数：普通药水 300 次、喷溅/滞留 210 次（服务端配置 `usesDrinkable` / `usesSplash` / `usesLingering`）。
  - **剑刃**：每个真正受伤的目标消耗 1 次（横扫 5 只 = 5 次），同一次挥击同目标只结算一次
  - **剑柄 / 盔甲**：每 30 秒消耗 1 次并刷新效果；效果在下一个周期前消失（到期、被牛奶清掉、被顶掉）时补扣 1 次并立即重贴
  - 盔甲上的瞬间治疗/伤害涂层保持 0.5 秒触发一次

### 附魔

| 附魔 | 作用 |
| --- | --- |
| 粘滞（Sticky） | 消耗次数时有概率不扣 |
| 强化（Amplification） | 提高涂层效果等级 |
| 叠加（Stacking） | 命中时概率把目标身上的负面效果再抬一级 |
| 注射（Injection） | 目标拒绝效果时强制注入 |
| 薛定谔的祝福（Schrödinger's Blessing） | 触发时随机换成另一种效果 |

附魔通过 `data/envenom/enchantment/*.json` 注册，可在附魔台/战利品中获得。

### 状态效果

| 效果 | 说明 |
| --- | --- |
| `envenom:nausea`（反胃） | 施加时清掉所有有益效果、饱和度归零；持续期间拒绝新的有益效果，且不能进食/饮用（含牛奶、蛋糕） |
| `envenom:vulnerability`（易伤） | 受到的伤害 × `(1 + 0.2 × (等级 + 1))`，在护甲减免之前结算 |
| 中毒（原版改造） | III 级起固定每 10 tick 结算；V 级起伤害 10 + 2.4×(级-4)，不致死（会被易伤打破） |
| 再生（原版改造） | V 级起每 tick 回血 `2^级 / 50` |
| `minecraft:nausea` | 仅改名「眩晕 / Vertigo」，行为不变 |

另有药水 **动若脱兔**（速度 + 易伤）：神龟大师 + 发酵蜘蛛眼酿造，有普通/延长/强化三档。

### 药包

共 **66 个**：16 个基础药包 + 50 个变体药包。

- 基础药包：**纸 + 原料**；需要「粗制」的药水额外加 **下界疣**
- 变体药包：基础药包 + 修正材料
  - 延长：+ 红石（11 种）
  - 强化：+ 荧石粉（7 种）
  - 喷溅：+ 火药（16 种）
  - 滞留：+ 龙息（16 种）
- 酿造：**水瓶 + 药包 → 对应药水/瓶型**，跳过下界疣与粗制步骤

完整配方表见 [docs/potion-packs.md](docs/potion-packs.md)。

## 女巫交易（两条版本线）

女巫改为对玩家中立：不会主动选择玩家为攻击目标，被玩家伤害后仍会反击。
普通右键打开「女巫药剂师」交易界面；潜行右键保留原有物品交互。
战斗中或刚受伤时不能交易，一次只接待一名玩家。离开超过 4 格、死亡、切换维度或女巫被移除时结束交易，未使用的付款按原版交易界面规则返还。

| 支付 | 获得 | 每次补货库存 |
| --- | --- | --- |
| 16 下界疣 | 1 绿宝石 | 8 |
| 12 玻璃瓶 | 1 绿宝石 | 8 |
| 3 绿宝石 | 1 治疗药水 | 8 |
| 4 绿宝石 | 1 抗火药水 | 8 |
| 4 绿宝石 | 1 喷溅虚弱药水 | 8 |
| 6 绿宝石 | 1 动若脱兔药水 | 4 |
| 2 / 3 / 3 / 4 / 5 绿宝石 | 1 迅捷 / 治疗 / 剧毒 / 力量 / 再生药包 | 各 8 |

库存由每只女巫独立保存，多人共享，重新打开界面或重载实体不会恢复库存。
距上次补货满 24000 游戏刻后，下次打开交易时补货；价格固定，没有村民等级机制。
首次成功打开交易界面会阻止这只女巫因距离自然消失。女巫仍沿用原版刷怪、袭击和和平难度移除规则；这里的中立指对玩家的攻击行为。

开发验证：两条版本线各有 `EnvenomWitchGameTests`，覆盖中立与反击、库存持久化与补货、交易扣款与关闭返还。1.21.1 使用 `runGameTestServer`；26.1.2 的测试由 `EnvenomTestFunctions` 和 `test_instance` 数据注册。

## 安装

1. 安装对应版本的 NeoForge（1.21.1 用 21.1.248+；26.1.2 用 26.1.2.122+）
2. 把对应 jar 放进 `mods/`
3. 客户端和服务端都需要安装（涂药结算在服务端，tooltip/染色在客户端）

## 构建

### Gradle（需要网络）

```bash
# 1.21.1（仓库根目录）
./gradlew build

# 26.1.2
cd mc26.1.2
./gradlew build
```

### 离线脚本（作者环境用）

仓库提供 `build-1.21.1.ps1` 与 `mc26.1.2/build-26.1.2.ps1`，只依赖 JDK 和 `libs-*` 目录。
`libs-*` 里是 Mojang / NeoForge 的二进制，**不随仓库分发**：

- `libs-1.21.1/`：NeoForge 21.1.248 的 merged jar + 21.1 服务端 libraries
- `libs-26.1.2/`：`minecraft-client-patched-26.1.2.122.jar` + `neoforge-26.1.2.122-universal.jar` + 官方 libraries + mixinextras

收集好后：

```powershell
.\build-1.21.1.ps1 -Clean -Verify
.\mc26.1.2\build-26.1.2.ps1 -Clean -Verify
```

脚本通过 `JAVA_HOME`（或 `-JdkHome`）寻找 JDK。
