# 涂层机制

## 槽位

| 槽位 | 载体 | 触发对象 | 时机 |
| --- | --- | --- | --- |
| 剑刃 BLADE | 武器 | 被攻击的目标 | 每次造成伤害 |
| 剑柄 HILT | 武器 | 持有者自己 | 每 30 秒 |
| 盔甲 ARMOR | 已穿戴的人形盔甲 | 穿戴者自己 | 每 30 秒 |

## 涂药

一只手拿药水，另一只手拿目标物品，右键：

- 副手药水 + 主手武器 → 剑刃
- 副手药水 + 主手盔甲 → 盔甲
- 主手药水 + 副手武器 → 剑柄

药水可以是普通、喷溅或滞留瓶；涂层继承药水的效果、等级和时长。

## 清洗

| 清洗物 | 效果 |
| --- | --- |
| 水瓶 | 去掉一层 |
| 蜂蜜瓶 | 去掉负面效果涂层 |
| 牛奶桶 | 去掉全部（不消耗桶） |

## 消耗

- **剑刃**：每个真正受伤的目标扣 1 次；同一次挥击对同一目标只结算一次；横扫/多目标各算一次
- **剑柄 / 盔甲**：每 30 秒扣 1 次并刷新；效果在下一个周期前消失（自然到期、被牛奶清除、被顶掉）时补扣 1 次并立即重贴
- **盔甲上的瞬间治疗/伤害**：0.5 秒触发一次（逐次扣次）
- 粘滞附魔有概率不扣；滞留涂层一次施加 3 次、扣 3 次

## 附魔

| 附魔 | 作用 |
| --- | --- |
| 粘滞 Sticky | 扣次时有概率豁免 |
| 强化 Amplification | 提高涂层效果等级 |
| 叠加 Stacking | 命中时概率把目标负面效果再抬一级 |
| 注射 Injection | 目标拒绝时强制注入 |
| 薛定谔的祝福 Schrödinger's Blessing | 触发时随机换成另一种效果 |

## 存档数据

涂层存在物品组件里（`envenom:coatings`），冷却和效果到期时间也存在物品上
（`envenom:trigger_cooldowns`、`envenom:applied_until`），随物品持久化、可跨存档。

## 配置

`config/envenom-server.toml`：

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `usesDrinkable` | 300 | 普通药水涂层次数 |
| `usesSplash` | 210 | 喷溅药水涂层次数 |
| `usesLingering` | 210 | 滞留药水涂层次数 |
| `vulnerabilityPerLevel` | 0.2 | 易伤每级增加的受伤倍率 |
