# 1.2.2 源码检查记录

检查基线：`eb6be84`（试剂剑回退后的版本）。范围包括两个版本的涂层结算、注射入口、中毒／凋零、牛奶和女巫交易逻辑。

## 已修复

| 问题 | 触发条件与影响 | 修复 |
| --- | --- | --- |
| 高等级中毒可能致死 | 中毒 V 对 10 点生命先取 9 点伤害，随后易伤再放大，突破非致死限制 | 为自定义中毒脉冲标识伤害来源，在最终伤害事件再次限制生命损失；保留原注册伤害类型，其他魔法和凋零伤害不受此限制 |
| 无限涂层时长丢失 | `-1` 被蓄力缩放取下限为 20 tick，或被滞留倍数乘成 `-3` | 缩放、倍乘和被动补充记录均保留无限语义，极长有限时长使用饱和运算 |
| 瞬间药效数值溢出 | amplifier 31 时 `1 << amplifier` 为负，32 时又回到 1；治疗可能变为负值 | 沿用再生的 amplifier 30 安全上限，普通等级数值保持一致 |
| 亡灵盔甲涂层判断错误 | 满血亡灵跳过本应伤害它的瞬间治疗，却持续消耗本应治疗它的瞬间伤害涂层 | 满血判断根据目标的治疗／伤害反转属性计算 |

## 排除的疑点

涂层在伤害事件中读取蓄力，并不会因原版提前清零而固定降为低强度：NeoForge 两个版本的官方 `Player` 补丁都将清零操作移到了攻击末尾。既有涂层测试已改为通过真正的 `Player.attack` 路径验证完整时长。

## 验证

- 两个版本的 `CoatingMath` 分别用 Java 21、Java 25 编译，运行 `tests/CoatingMathCheck.java` 均通过。覆盖无限时长、有限时长溢出、常规数值，以及 amplifier 0 至 255 的非负、有限、单调性。
- 两个版本的 Gradle `processResources` 均成功；全部资源 JSON 可解析，Mixin 类存在，26.1.2 的 44 个测试注册均能对应源码方法与测试资源。
- 两版本各新增四组 GameTest，覆盖上述问题，并检查普通魔法仍可致死。
- **完整编译与 GameTest 未运行成功**：`createMinecraftArtifacts` 阶段缺少 NeoForm Runtime 2.0.24／2.0.31 缓存。环境此前对所需依赖仓库的下载返回 403。数值检查不能替代实际游戏验证，也未验证任意第三方模组对最终伤害事件的再次改写。

独立数值检查（在仓库根目录，使用 Java 21 或以上）：

```sh
mkdir -p /tmp/envenom-math-check
javac -d /tmp/envenom-math-check src/main/java/com/terminalfoam/envenom/handler/CoatingMath.java tests/CoatingMathCheck.java
java -cp /tmp/envenom-math-check CoatingMathCheck
```

检查另一个版本时，将上述源码路径换成 `mc26.1.2/src/main/java/com/terminalfoam/envenom/handler/CoatingMath.java`。
