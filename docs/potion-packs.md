# 药包配方

所有药包都是无序合成，`group = envenom_potion_pack`，产出 1 个。

- **基础药包** = 纸 + 原料（需要「粗制」的药水再加 **下界疣**）
- **变体药包** = 基础药包 + 修正材料
- 酿造：**水瓶 + 药包 → 对应药水/瓶型**

## 基础药包（16）

| 药包 | 原料 | 下界疣 | 水瓶酿出 |
| --- | --- | --- | --- |
| `swiftness_pack` | 糖 | 否 | 迅捷 |
| `leaping_pack` | 兔子脚 | 是 | 跳跃 |
| `strength_pack` | 烈焰粉 | 是 | 力量 |
| `healing_pack` | 闪烁的西瓜片 | 是 | 治疗 |
| `poison_pack` | 蜘蛛眼 | 是 | 中毒 |
| `regeneration_pack` | 恶魂之泪 | 是 | 再生 |
| `fire_resistance_pack` | 岩浆膏 | 是 | 抗火 |
| `water_breathing_pack` | 河豚 | 是 | 水肺 |
| `night_vision_pack` | 金胡萝卜 | 是 | 夜视 |
| `turtle_master_pack` | 海龟壳 | 是 | 神龟大师 |
| `slow_falling_pack` | 幻翼膜 | 是 | 缓降 |
| `weakness_pack` | 发酵蜘蛛眼 | 否 | 虚弱 |
| `wind_charged_pack` | 旋风棒 | 是 | 风弹 |
| `weaving_pack` | 蜘蛛网 | 是 | 织网 |
| `oozing_pack` | 粘液块 | 是 | 渗浆 |
| `infested_pack` | 石头 | 是 | 寄生 |

> 速度、虚弱在原版就是水瓶起步，所以不加下界疣；其余 14 种需要粗制。

## 变体药包（50）

| 基础药水 | 延长（红石） | 强化（荧石粉） | 喷溅（火药） | 滞留（龙息） |
| --- | --- | --- | --- | --- |
| 迅捷 | ✓ | ✓ | ✓ | ✓ |
| 跳跃 | ✓ | ✓ | ✓ | ✓ |
| 力量 | ✓ | ✓ | ✓ | ✓ |
| 治疗 | — | ✓ | ✓ | ✓ |
| 中毒 | ✓ | ✓ | ✓ | ✓ |
| 再生 | ✓ | ✓ | ✓ | ✓ |
| 抗火 | ✓ | — | ✓ | ✓ |
| 水肺 | ✓ | — | ✓ | ✓ |
| 夜视 | ✓ | — | ✓ | ✓ |
| 神龟大师 | ✓ | ✓ | ✓ | ✓ |
| 缓降 | ✓ | — | ✓ | ✓ |
| 虚弱 | ✓ | — | ✓ | ✓ |
| 风弹 | — | — | ✓ | ✓ |
| 织网 | — | — | ✓ | ✓ |
| 渗浆 | — | — | ✓ | ✓ |
| 寄生 | — | — | ✓ | ✓ |

- 延长 = `long_<基础>_pack`，强化 = `strong_<基础>_pack`
- 喷溅 = `splash_<基础>_pack`，滞留 = `lingering_<基础>_pack`
- 喷溅/滞留包通过自定义酿造配方直接产出对应瓶型；延长/强化包产出对应药水

## 数量

16 基础 + 11 延长 + 7 强化 + 16 喷溅 + 16 滞留 = **66 个药包**。
